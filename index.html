올린 사진은 내가 연필로 그린 유니버설 디자인 제품 스케치야. 선의 위치와 비례를 그대로 두고, 깔끔한 제품 디자인 시안으로만 다듬어 줘.
이건 [ 누구 ]를 위한 [ 무엇 ]이고, [ 기능·특징 ]이 있어. [ 재질·색 ], [ 앞면 ]에서 본 모습. 흰 배경에 제품 하나만. 없던 부품을 만들거나 모양을 예쁘게 바꾸지 마. 글자·사람·로고는 넣지 마.

예)　[ 손에 힘이 약한 사람 ]　[ 문손잡이 ]　[ 팔꿈치로 눌러 여는 레버 · 미끄럼 방지 홈 ]　[ 무광 나무 + 검은 고무 ]　[ 앞면 ] 모양이 바뀌어 나오면 → “내 스케치 선을 그대로 따라 그려. 새로 디자인하지 마.” 한 줄 더 보내기
